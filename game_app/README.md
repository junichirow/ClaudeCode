# クマクマシューティング

ブラウザで遊べるシンプルな縦スクロールシューティングゲームです。クマのぬいぐるみを操作して敵を倒し、ときどき現れるサメのボスや、大ボスのシロクマに挑みます。HTML / CSS / JavaScript（Canvas）だけで作っていて、ライブラリやビルドは不要です。

## 遊び方

| 操作 | キーボード | スマホ |
| --- | --- | --- |
| 移動 | 矢印キー / WASD | 画面をドラッグ |
| ショット | スペース（長押しで連射） | タッチ中は自動連射 |
| 一時停止 | P | - |
| 音のオン / オフ | M | - |
| スタート / リトライ | Enter / スペース / クリック | タップ |

- 敵を倒すとスコアが入り、1500 点ごとにレベルが上がって敵が増えます
- レベル 2 からジグザグに動く敵、レベル 3 から硬い大型の敵が出てきます
- 3000 点ごとにサメのボスが登場します。扇状の弾と口からの狙い撃ちに注意。倒すと 3000 点
- サメを 2 回倒すと、3 回目のボスは赤白ボーダーの T シャツを着た大ボスのシロクマになります（以降、サメ → サメ → シロクマのくり返し）。全方位の輪っか弾と両手からの 3 方向弾を撃ち、体力が半分を切ると目が赤く光ってうずまき弾も加わります。倒すと 10000 点
- ライフは 3。敵の弾か敵本体に当たると減ります
- ハイスコアはブラウザ（localStorage）に保存されます
- BGM（通常面とボス戦の2曲）と効果音は Web Audio API でその場で合成しています。音声ファイルは使っていません。音のオン / オフ設定も localStorage に保存されます

## ローカルで動かす

`index.html` をブラウザで開くだけで遊べます。ローカルサーバーを使う場合：

```bash
cd game_app && python -m http.server 8000   # http://localhost:8000
```

## ファイル構成

- `index.html` — ページ本体
- `style.css` — 見た目
- `game.js` — ゲームのロジックと描画
- `sound.js` — BGM と効果音（Web Audio API）
