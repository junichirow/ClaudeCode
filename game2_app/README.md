# クマクマ大冒険

ブラウザで遊べる横スクロールアクションゲームです。赤いグローブをつけた茶色のクマを操作し、パンチとジャンプで森を進みます。小さなシロクマたちを倒しながら、ゴールで待つ大ボスのシロクマに挑みます。HTML / CSS / JavaScript（Canvas）だけで作っていて、ライブラリやビルドは不要です。

## 遊び方

| 操作 | キーボード | スマホ |
| --- | --- | --- |
| 移動 | ← → / A D | ◀ ▶ ボタン |
| ジャンプ | スペース / ↑ / W（長押しで高く跳ぶ） | ジャンプボタン |
| パンチ | Z / X / J | パンチボタン |
| 一時停止 | P | 画面右上の Ⅱ |
| 音のオン / オフ | M | 画面右上の ♪ |
| スタート / リトライ | スペース / Enter / クリック | タップ |

- 敵（小さなシロクマ）はパンチで倒すか、上から踏んで倒せます。1 体 100 点
- はちみつのつぼは 50 点、ハートは HP が 1 回復します（HP が満タンなら 500 点）
- HP は 3。敵に体当たりされると減り、0 になるか穴に落ちるとミスになります。クマは 3 匹で、全部いなくなるとゲームオーバー
- 途中の旗はチェックポイントです。ミスすると最後に通った旗からやり直します（敵は元に戻ります）
- ステージの最後で、赤白ボーダーの T シャツを着た大ボスのシロクマが登場します。歩いて近づく・大ジャンプ（着地すると左右に衝撃波が走るのでジャンプでよける）・雪玉投げの 3 つの技を使います。雪玉はパンチで打ち返せます。体力が半分を切ると怒って速くなり、雪玉を 3 つ投げるようになります
- ボスを倒すとステージクリア。早くクリアするほどタイムボーナス、残っているクマの数に応じてボーナスが入ります
- ハイスコアはブラウザ（localStorage）に保存されます
- BGM（森の曲とボス戦の曲）と効果音は Web Audio API でその場で合成しています。音声ファイルは使っていません

## ローカルで動かす

`index.html` をブラウザで開くだけで遊べます。ローカルサーバーを使う場合：

```bash
cd game2_app && python -m http.server 8000   # http://localhost:8000
```

スマホで試すときは、PC と同じ Wi-Fi につないで `python -m http.server 8000 --bind 0.0.0.0` で起動し、スマホから `http://<PC の IP アドレス>:8000` を開きます。

## 公開

`main` にプッシュすると、GitHub Actions（`.github/workflows/pages.yml`）で GitHub Pages の `/game2/` に公開されます。

## ファイル構成

- `index.html` — ページ本体とスマホ用ボタン
- `style.css` — 見た目（タッチ操作の端末ではボタンを表示。横向きのスマホではゲームを画面いっぱいに出し、ボタンを重ねる）
- `game.js` — ステージ・操作・敵・ボスのロジックと描画。ステージは `buildLevel()` の中で地面・足場・敵・アイテムを置いて作っている
- `sound.js` — BGM と効果音（Web Audio API）
