# クマクマ大冒険

ブラウザで遊べる横スクロールアクションゲームです。赤いグローブをつけた茶色のクマを操作し、パンチ・ジャンプ・レーザーで森を進みます。全 2 ステージ。1 面は森で小さなシロクマと大ボスのシロクマ、2 面は竹林でミニパンダと大ボスのパンダが相手です。HTML / CSS / JavaScript（Canvas）だけで作っていて、ライブラリやビルドは不要です。

## 遊び方

| 操作 | キーボード | スマホ |
| --- | --- | --- |
| 移動 | ← → / A D | ◀ ▶ ボタン |
| ジャンプ | スペース / ↑ / W（長押しで高く跳ぶ） | ジャンプボタン |
| パンチ | Z / X / J | パンチボタン |
| レーザー | C / K | レーザーボタン |
| 一時停止 | P | 画面右上の Ⅱ |
| 音のオン / オフ | M | 画面右上の ♪ |
| スタート / リトライ | スペース / Enter / クリック | タップ |

- 敵（1 面は小さなシロクマ、2 面はミニパンダ）はパンチで倒すか、上から踏んで倒せます。1 体 100 点
- レーザーは 10 秒に 1 回だけ撃てる強い技です。少しためてから、向いている方向の画面の端までビームが伸びます。当たった敵はまとめて倒せて、雪玉や衝撃波も消せます。大ボスにはパンチ 4 回分のダメージ。撃っている間は無敵で、空中で撃つとその場に止まります。左上のゲージ（スマホはボタンの表示）で次に撃てるまでの時間がわかります
- はちみつのつぼは 50 点、ハートは HP が 1 回復します（HP が満タンなら 500 点）
- HP（ハート）は 5。敵に体当たりされると減り、0 になるか穴に落ちるとミスになります。クマは 3 匹で、全部いなくなるとゲームオーバー
- 途中の旗はチェックポイントです。ミスすると最後に通った旗からやり直します（敵は元に戻ります）
- ステージの最後で、赤白ボーダーの T シャツを着た大ボスのシロクマが登場します。歩いて近づく・大ジャンプ（着地すると左右に衝撃波が走るのでジャンプでよける）・雪玉投げの 3 つの技を使います。雪玉はパンチやレーザーで壊せます。体力が半分を切ると怒って速くなり、雪玉を 3 つ投げるようになります
- 2 面の最後には大ボスのパンダが登場します。シロクマと同じ技（雪玉のかわりにタケノコを投げる）に加えて、丸まって部屋の端から端まで転がってくる技を使います（壁で 2 回はね返ると止まる）。体力はシロクマより多めです
- ボスは上から踏むと 3 秒間目を回して動けなくなります（目を回している間にもう一度踏んでも時間はのびません）
- ボスを倒すとステージクリア。早くクリアするほどタイムボーナス、残っているクマの数に応じてボーナスが入ります。1 面をクリアするとスコアと残りのクマを引きついで 2 面へ進みます。ゲームオーバーになっても、やられたステージの最初からコンティニューできます（スコアは 0 に戻り、クマは 3 匹にもどります）
- ハイスコアはブラウザ（localStorage）に保存されます
- BGM（森の曲・竹林の曲・ボス戦の曲）と効果音は Web Audio API でその場で合成しています。音声ファイルは使っていません

## ローカルで動かす

`index.html` をブラウザで開くだけで遊べます。ローカルサーバーを使う場合：

```bash
cd game2_app && python -m http.server 8000   # http://localhost:8000
```

URL の末尾に `?stage=2` をつけると 2 面から始められます（動作確認用）。

スマホで試すときは、PC と同じ Wi-Fi につないで `python -m http.server 8000 --bind 0.0.0.0` で起動し、スマホから `http://<PC の IP アドレス>:8000` を開きます。

## ファイル構成

- `index.html` — ページ本体とスマホ用ボタン
- `style.css` — 見た目（タッチ操作の端末ではボタンを表示。横向きのスマホではゲームを画面いっぱいに出し、ボタンを重ねる）
- `game.js` — ステージ・操作・敵・ボスのロジックと描画。ステージは `layoutStage1()` / `layoutStage2()` の中で地面・足場・敵・アイテムを置いて作っている。ステージごとの名前・BGM・ボスの体力は `STAGES` にまとめている
- `sound.js` — BGM と効果音（Web Audio API）
